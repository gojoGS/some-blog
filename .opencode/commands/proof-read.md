---
description: Proofread an AsciiDoc document without modifying it.
---

proof read $ARGUMENTS

main tasks:
- check grammar errors, typos, spelling errors
- check text formatting, hyphenation, commas
- check for logical errors
- check for repetitive, inconsistent, redundant wording
- check for cohesive "story", clear chain of thought, theme presentation. No jumping in the "story"
- check consumability of content, check for too frequent long sentences, check monotonity of text.
- check correct use of markup semantics, correct use of headers, leads, lists, listings, etc, asciidoc semantic toolkit


Annotation:
- write AsciiDoc comments above the block containing the error
- explain the error
- give suggestion/proposed solution if applicable

don't correct your findings without the user's explicit command.
