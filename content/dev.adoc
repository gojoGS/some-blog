== Inline formatting

Normal text with *bold*, _italic_, `monospace`, *_bold italic_*, #mark#,
and [.line-through]#strikethrough#.

Subscript H~2~O and superscript E=mc^2^. Keyboard input: kbd:[Ctrl] + kbd:[T],
menu:File[Save As], btn:[Save], and key combination kbd:[Ctrl,Alt,Del].

Escape any text *not* formatted: pass:[<b>raw HTML passthrough</b>].

== Code

Inline code: `puts "hi"`. A fenced code block:

[source,json]
----
{
  "hello": "world",
  "nested": [1, 2, 3]
}
----

A source block with callouts:

[source,ruby]
----
puts "hello" # <1>
sleep 1      # <2>
----
<1> Prints a greeting.
<2> Pauses a second.

A literal block:

....
this   is   preformatted
    whitespace   preserved
....
